# Entrada/

Trazabilidad de qué instancias se han probado con esta metaheurística.
Cada corrida real ya deja una copia exacta de su instancia dentro de
`../Salida/dd_mm_aaaa_hh_mm_ss/forma1.txt` — esta carpeta es un índice más
liviano para no tener que revisar carpeta por carpeta.

Convención: cuando se corre una instancia nueva contra este método por
primera vez, se copia acá (o se agrega una línea a un manifiesto, si el
equipo prefiere eso a copiar archivos completos).
